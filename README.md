# hingemark

Hinge identifiers and mark tokens for idempotent workflows.

**Site:** https://theworker02.github.io/hingemark/

## Install / run

```bash
git clone https://github.com/theworker02/hingemark.git
cd hingemark
node src/cli.js
node --test
```
